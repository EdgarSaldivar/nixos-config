# Relocating the traefik file provider — the last two bindings

**Status: ✅ EXECUTED 2026-08-16.** Kept as the record of how it was done and what
it cost, not as a plan.

`routeDir` and the Pod's hostPath both point at `/usr/local/etc/traefik`,
`checks/external-checkout-dependency.nix` is at zero entries, and
`/home/edgar/git/docker` has been deleted.

⛔ This header previously read "PREPARED, NOT EXECUTED" and told the reader to delete
the check and the directory "when it lands" — after all three had already happened.
Cross-review flagged the contradiction on 2026-08-18: a runbook that misreports its
own status is worse than no runbook, because it invites someone to re-run a migration
that is already done.

⚠️ One thing the original move did NOT do, fixed 2026-08-18: nothing in the
repository created the destination directory. It existed only because it was made by
hand during the relocation, so a rebuild-from-scratch of minas would have aborted on
the activation guard. `traefik-routes.nix` now creates it.

⛔ **This one is not like immich and shelfmark.** Read the "why it is different"
section before planning a window.

## The two bindings

| | |
|---|---|
| `traefik-routes.nix:56` | `routeDir = "/home/edgar/git/docker/infra/traefik"` — minas **activation writes** the generated route files here on every rebuild |
| `manifests/traefik.yaml:230` | the traefik Pod bind-mounts the same directory, `type: Directory`, as its file provider |

A producer on **minas** and a consumer on **pelargir's** cluster, pointed at one
directory on minas' disk. They must move together.

## Why it is different from the last two

immich and shelfmark were *config directories a Pod read*. This is a directory a
**host activation writes into and a Pod reads from**, and the Pod is the singleton
public ingress.

1. **You cannot simply point it at the Nix store.** The store is read-only, and
   activation installs files here on every rebuild. Either the generated routes
   become a store-resident directory (and activation stops writing), or the new
   location is another mutable path on minas.
2. **Changing the hostPath edits `spec.template`.** With `strategy: Recreate` on a
   pinned singleton that is a **full ingress outage for all 26 hostnames**, not a
   rolling update. Unlike the previous moves, `kubectl diff` *will* legitimately
   show a template change — so it cannot be used as the "no template change" proof.
3. **`acme.json` must never have two writers.** Rollback is another declarative
   hostPath switch — **never** start an old docker traefik alongside.

## ✅ The hard part is already gone (2026-08-16)

When this runbook was first written the directory held 25 generated files **plus a
hand-maintained `traefik.yml`** — 5 middlewares, 5 routers, 3 services, and a
bcrypt credential in plaintext. Carrying that into a managed location was the
difficult, open question.

It turned out to be entirely redundant, and it has been **deleted**:

- its four `dungeon-*` routers pointed at `192.168.6.94`, a dead host (`000`)
- its `traefik-router` was **shadowed**: the generated `k8s-authentik-gate.yml`
  already routes `traefik.saldivar.io` → `api@internal` at **priority 9000**,
  against the hand-maintained router's default (~30)
- `basic-auth` was used only by that shadowed router; no generated route
  references any of the five middlewares (checked individually, zero hits each)
- the `entryPoints` / `accessLog` / `certificatesResolvers` blocks are static keys
  traefik **ignores** in a dynamic file — visible proof: they declare
  `web`/`websecure` while the live routers use `https`

Verified by removing it and re-running the full external acceptance from pelargir
against the recorded baseline: **pass**, with `traefik.saldivar.io` still
redirecting to authentik. Rollback sits at `/var/tmp/traefik.yml.disabled`.

**The directory is now 0 hand-maintained files and 25 generated ones.** So this
move no longer has to solve "how do we manage an unmanaged file"; it only has to
change where activation writes and where the Pod reads.

static configuration own that.

## Sequence

Ordered so the risky step is as short and as reversible as possible.

**1. Freeze and capture.** No unrelated route edits during this. Record:

```sh
# the acceptance baseline, from OUTSIDE, is the thing you must reproduce
python3 hosts/nixos/minas-tirith/scripts/ingress-acceptance.py \
  --baseline hosts/nixos/minas-tirith/baselines/minas-ingress-authentik-baseline-*.txt \
  --public-dns --monitor-certificate
sudo cp -a /home/edgar/git/docker/infra/traefik /var/tmp/traefik-rollback-$(date -u +%Y%m%dT%H%M%SZ)
```

⚠️ Settle the expected host set before starting. `traefik-hostnames.nix` lists 27
names, prose says 26, and the baseline has 27 rows but substitutes `dungeon` --
whose routing is now retired but whose DNS still resolves -- for the staged `pin`. Know exactly what "all green" means *before* you
can no longer roll forward.

**2. Dual-write, minas only.** Change activation to install the generated files
into **both** the old and the new directory. Rebuild **minas** alone. The live Pod
still reads the old path, so this is a no-op for traffic — and it means the new
directory is complete and warm before anything switches.

Nothing else to seed: since 2026-08-16 the directory holds only generated files.

**3. Prove the new directory before switching.** Contents must match, ignoring
nothing:

```sh
sudo rsync -aHAXn --itemize-changes --delete \
  /home/edgar/git/docker/infra/traefik/ /new/path/     # must be empty
```

**4. The switch — this is the outage.** Change `manifests/traefik.yaml`'s hostPath
and rebuild **pelargir**. `Recreate` means the Pod goes down and comes back.

```sh
kubectl -n traefik rollout status deploy/traefik --timeout=180s
kubectl -n traefik get deploy traefik -o jsonpath='{..hostPath.path}'; echo
```

**5. Acceptance — not readiness.** A Ready Pod proves it started, nothing about
routing. Re-run the full external acceptance from step 1 and require the *exact*
recorded statuses. Six hostnames are healthy at 302/401/303; a 200 there means a
middleware was dropped.

Also verify the certificate identity and expiry, and that the dashboard still
requires auth.

**6. Retire.** Once soaked: change activation to write only the new directory,
remove the final two entries from `checks/external-checkout-dependency.nix`,
rebuild minas, and delete the check plus `/home/edgar/git/docker` together.

## Rollback

Declarative hostPath switch back to the old directory, rebuild pelargir. The old
directory is still being dual-written at that point, so it is current — that is
the reason step 2 exists.

⛔ **Never** start a docker traefik as a rollback. Two writers on `acme.json` is
how you lose the wildcard certificate, and `acme.json` snapshots have a shelf life:
after a renewal, restoring an old copy discards newer certificates and account
state.
